# Flipkart Order Intelligence & Support Assistant

A three-part connected ML system: a return-risk scoring model, a product-image
categoriser via transfer learning, and a LangGraph support agent that calls
both as real tools on top of a retrieval-augmented policy knowledge base.

```
repo_root/
  part1_return_risk/       Task 1-9: return-risk model (sklearn)
  part2_image_classifier/  Task 1-8: image categoriser (PyTorch transfer learning)
  part3_agent/              Task 1-10: LangGraph support agent
```

---

## Part 1 -- Return-Risk Scoring Pipeline

**Status: Complete and verified end-to-end.**

```
cd part1_return_risk
py -m pip install -r requirements.txt
py generate_orders.py       # regenerates orders_dataset.csv (seeded, deterministic)
py preprocessing.py         # self-test of the leak-free preprocessing pipeline
py task4_baseline.py        # DummyClassifier baseline
py task5_logreg.py          # Logistic Regression + threshold sweep
py task6_random_forest.py   # GridSearchCV-tuned Random Forest
py task7_feature_importance.py
py task8_subgroup_analysis.py
py task9_save_artifact.py   # saves models/return_risk_model.pkl + risk_threshold_config.json
```

Full written analysis (Tasks 2, 4, 5, 7, 8): see `part1_return_risk/PART1_REPORT.md`.

**Key results:**
- Dataset: 6,000 rows, 22.75% return rate, `rating_given` missing MAR
  (conditioned on `payment_method`, 16.77pp gap between COD and non-COD).
- Random Forest (GridSearchCV-tuned): CV ROC-AUC 0.6178, test ROC-AUC 0.6143.
- Final artifact: `models/return_risk_model.pkl`, anchored threshold
  `t*_rf = 0.46`.

## Part 2 -- Product Image Categoriser (Transfer Learning)

**Status: Code complete, NOT yet executed** (no GPU/torch environment
available while building this). Must be run locally -- see
`part2_image_classifier/PART2_REPORT.md` for the exact run order and the
result placeholders to fill in from your own run.

```
cd part2_image_classifier
py -m pip install -r requirements.txt
py task1_load_data.py
py task3_feature_extraction.py
py task4_finetune.py           # only if task3's val accuracy < 80%
py task5_evaluate.py
py task6_confusion_analysis.py
py task7_save_artifact.py      # saves models/product_classifier.pt
py task8_export_samples.py     # exports real test-split images to data/sample_images/
```

**Architecture:** ResNet-18 pretrained backbone, frozen except a new 10-class
head; frozen-backbone features are cached to disk once so the head trains in
seconds instead of re-running the backbone every epoch (CPU-friendly). If
feature-extraction-only validation accuracy is below 80%, `layer4` is
unfrozen for a short gradual fine-tune at a lower learning rate.

## Part 3 -- Flipkart Support Agent (LangGraph)

**Status: Code complete, NOT yet executed** (same environment limitation as
Part 2, plus no `langgraph`/`faiss`/network access available while building
this). Must be run locally after Parts 1 and 2 are both done -- see
`part3_agent/PART3_NOTES.md` for the exact run order and a spot-check
procedure proving the tools call the real saved models.

```
cd part3_agent
py -m pip install -r requirements.txt
py build_index.py           # embeds 14-doc policy KB, builds FAISS index
py run_transcripts.py       # generates all 8 required transcripts
py evaluate_retrieval.py    # Precision@3 / Recall@3, document-level
```

**Graph:** 5 nodes (guardrail -> intent -> [retrieval | tool] -> response),
2 conditional edges. Runs in `MOCK_LLM` mode by default -- zero API keys,
zero network calls. `check_return_risk` and `classify_product_image` load
Part 1's and Part 2's actual saved artifacts (no hardcoded stand-ins).

**Transcripts** (`part3_agent/transcripts/`, generated by `run_transcripts.py`):
1. Policy question #1 (RAG)
2. Policy question #2 (RAG)
3. Return-risk question (calls `check_return_risk`)
4. Product-category question (calls `classify_product_image`)
5. Multi-turn exchange -- state **carried** across turns
6. Fresh conversation -- same phrasing, state correctly **absent**
7. Prompt-injection attempt -- visibly **blocked**
8. Ungrounded policy question -- visibly **refused**, similarity score printed
